# BIO-SAWTOOTH Sample

## Overview

This example generates a 12-bit sawtooth waveform using only BIO assembly instructions.

The BIO core operates at **700 MHz**. Each output step requires **40 clock cycles** (approximately 10 BIO instructions). Since a 12-bit waveform consists of **4096 steps** per period, the output frequency is calculated as:

$$700\text{MHz} \div (40 \times 4096) \approx 4.3,\text{kHz}$$
